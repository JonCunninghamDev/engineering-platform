# Engineering Platform v1.0.0

Engineering Platform v1.0.0 is the first complete consumer-ready release of the governed agent-native engineering platform.

## Included

- Basic Context, Orchestrator, Builder, and Verifier agent vertical slices;
- explicit versioned context, planning, assignment, change-set, verification, policy, and run-report contracts;
- tier-aware demo behavior with visible capability, autonomy, and execution boundaries;
- deterministic Builder diff and content-hash evidence;
- deterministic Verifier validation evidence;
- reusable consumer CI composed from generic capability and profile declarations;
- protected-path and branch-route policy enforcement;
- `main`/`develop` two-long-lived-branch delivery governance;
- explicit human approval for production release promotion;
- consumer-agnostic adoption, compatibility, failure-isolation, and rollback guidance.

## Consumer guidance

Consumers should verify this release, then pin both:

- tag: `v1.0.0`;
- immutable release commit: the commit targeted by this GitHub release.

Consumers must retain repository-specific product purpose, architecture, acceptance criteria, credentials, environments, risk exceptions, and other local truth. Platform contracts and workflows must remain consumer-agnostic.

## Compatibility

This release establishes the first stable 1.0 consumer contract. Consumers pinned to `v0.1.0` should adopt `v1.0.0` through a focused, tested upgrade pull request and retain their previous immutable pin for rollback.

## Validation

The release is published only after the complete Platform CI and required consumer-composition checks pass on the promoted `main` commit.

## Rollback

Consumers can revert their focused adoption or upgrade pull request and restore the previous immutable platform pin without depending on live platform availability.
