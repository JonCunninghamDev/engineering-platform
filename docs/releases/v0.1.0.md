# Engineering Platform v0.1.0

The first published shared steering baseline for JCDevBot repositories.

## Included

- repository authority and instruction precedence;
- deterministic startup and task selection;
- `main`, `develop`, feature, promotion, synchronization, and hotfix branch roles;
- automated validation followed by human acceptance for consequential goals;
- explicit human approval for shared steering and release promotion;
- pinned-consumer adoption with local product-specific steering and overrides;
- release verification using `README.md`, `VERSION`, and GitHub release metadata;
- repository layout, pull-request template, and Platform CI validation.

## Consumer guidance

Consumers should verify this release, then pin both:

- tag: `v0.1.0`;
- immutable release commit: the commit targeted by this GitHub release.

Consumers must retain local product vision, architecture, acceptance criteria, environments, credentials, and repository-specific exceptions.

## Compatibility

This is the first published baseline. No earlier consumer contract is superseded.

## Rollback

Consumers can revert the focused adoption pull request and restore their previous local steering without depending on remote platform availability.
